# Claims Boundary

## Validated claims

This repository may accurately state that, in the controlled lab test:

- Passwordless authentication was validated.
- The integrated AgentCore application remained functional.
- Microsoft Entra accepted the AWS assertion.
- Blueprint token T1 acquisition succeeded.
- Child Agent Identity resource token TR acquisition succeeded.
- Microsoft Graph returned HTTP 200.
- The returned identity matched the configured child Agent Identity.
- The returned service-principal type was `ServiceIdentity`.
- No Microsoft client secret was used in the tested path.
- No token values were returned in the controlled response.

## Explicit non-claims

This repository does not claim:

- Agent 365 Connected Platforms synchronization
- Automatic Agent 365 registration
- Agent 365 SDK onboarding
- Agent 365 Observability ingestion
- Microsoft Purview visibility
- Conditional Access enforcement
- Defender protection
- Full Agent 365 governance
- Production readiness
- Official Microsoft reference architecture status
- Microsoft or AWS product support, endorsement, or commitment
