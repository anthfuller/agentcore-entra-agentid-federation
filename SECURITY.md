# Security Policy

## Reporting a security issue

Report suspected vulnerabilities privately to the repository owner rather than opening a public issue.

Do not include credentials, access keys, secret keys, session tokens, Microsoft access tokens, AWS assertions, authorization headers, tenant identifiers, application or object identifiers, AWS account identifiers, ARNs, federation issuer URLs, customer information, corporate tenant details, or private CLI and runtime logs.

Use placeholders and sanitized reproductions. Revoke or rotate any sensitive value that was exposed before reporting it.

## Scope

This repository is a controlled-lab proof of concept. It is not a production security assessment, support channel, or official Microsoft or AWS reference implementation.
